# StaffChat
Simple LAN Streaming application built using OpenCV, Pickle, Struct, Pillow and Socket Programming, done for proof of concept.

To run, clone the repo and run pip install requirements.txt. Next, go to the file called "config.json" and change the *server_ip* parameter to the private ip-address of the host PC. Then run the server script on the host PC and run the client scripts on two separate instances, preferably on separate PCs with camera and microphone ability. To initiate a video call, simply type !REQUEST into the command bar on the presented client gui and follow instructions. 

Bugs still may be present, so please let me know! Enjoy!
